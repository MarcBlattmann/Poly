# How many 4-byte stack slots the arguments of a 32-bit `stdcall` function take (ADR 0186), for
# the functions Poly does not implement, so that the 32-bit `polystub.dll` can fail them and
# return (`ret 4n`) instead of ending the process. One per line: `dll!name slots [cdecl]`.
# Written from the prototypes on Microsoft Learn: every argument is one slot, `LONGLONG`,
# `DWORD64` and `double` two, a `POINT`/`SIZE` by value two, `FLOAT` one. `cdecl`: the caller
# pops (variadic functions such as `wsprintfA`), so the stub is a plain `ret`.
# A name that is not here still ends the process: add it (from its Learn page) when a program
# reaches it.

# `MsiEnumRelatedProductsW(lpUpgradeCode, dwReserved, iProductIndex, lpProductBuf)` is the call WinSCP makes with
# ordinal 205 (a string, 0, 0, a buffer).
