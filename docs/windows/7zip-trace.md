A "call" number is the call's index in its thread (thread 0 is the main thread). The outputs and files are the untraced scenario's to compare ([7zip-recording.md](7zip-recording.md)).

The documented normalisations (ADR 0110), applied to both sides: the work directory, as long on both systems, is `<work>`; local times in strings are UTC; results of time, tick and id functions and of `GetOEMCP` (the machine's code page) are `*`; `GetVersion` is compared as major.minor (the build is the machine's); `IsProcessorFeaturePresent` calls are left out (the processor's); `memset`'s fill value is compared as a byte. Nothing else is: every other result and last error is compared exactly.
